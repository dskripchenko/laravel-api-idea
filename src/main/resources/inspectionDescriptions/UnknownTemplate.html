Reports a response template named by @response 200 {Name}, @input @Model or @output @Model[] that getOpenApiTemplates() never declares.

The generator writes the name into the specification regardless, as a $ref at #/components/schemas/… that resolves to nothing. The document still validates, so nothing local complains; it breaks for whoever generates a client from it. One real installation carried 323 such references.

A quick fix declares the template, taking the name verbatim from the docblock.
