Reports mistakes that only show up when the docblock is read as a whole: a field declared twice, a nested field whose parent is never declared, a parent declared as the wrong kind of container, two answers for one status code.

In each case the generator keeps the last thing it saw and says nothing, so the specification quietly describes fewer fields — or fewer outcomes — than the docblock does.

A @default for a variable with no @input is deliberately not reported here: middleware contributes inputs of its own, and telling a stray default from a legitimate one needs the route map and the middleware chain resolved. php artisan api:lint does that with the application booted.
